# Certificação

O **Trilha-Dev: Python** oferece uma certificação de **XXh** para aqueles fizerem o curso.

### :octicons-arrow-right-24: Como conseguir o seu certificado

Para comprovar a sua participação, você deve apresentar cumprir os seguintes requisitos:

- Ter um fork do [repositório de exercícios](https://github.com/splor-mg/exercicios-python)em sua conta pessoal do Github.
- Resolver pelo menos 50% dos exercícios da pasta `01_essencial`. Esta verificação será feita por meio da badge `exercícios obrigatórios` disponível no `readme.md` do seu repositório.
- Resolver o desafio final conforme orientações abaixo.

### :octicons-arrow-right-24: Como solicitar o seu certificado 

O processo de solicitar o certificado também é uma forma de demonstrar os seus conhecimentos! :rocket:

Para tanto, você deverá:

- Abrir um [issue no repositório do Trilha - Dev](https://github.com/splor-mg/trilha-dev/issues) com o título: Solicitação de certificado.
- Você deve atribuir a @raianecardoso como _assignee_ deste issue.
- Na descrição do issue você deve preencher as seguintes informações:
    - Nome completo
    - CPF.
    - E-mail.
    - Órgão.
    - url do site.

**Bom trabalho e sucesso na sua jornada!** :sparkles::sparkles::sparkles:
